# Task 4 - Tableau Dashboard

## Call Center Performance Dashboard

This project presents an interactive Tableau dashboard designed to analyze call center performance.

### Tool Used

* Tableau

### Dataset

The dataset contains call center information such as:

* Agent Name
* Call ID
* Customer ID
* Call Duration
* Call Pickup Status
* Product Sold

### Dashboard KPIs

* Total Calls
* Total Customers
* Average Call Duration
* Calls Picked Up
* Products Sold

### Visualizations

* Calls by Agent
* Products Sold by Agent
* Call Pickup Status
* Average Call Duration by Agent
